# Audio asset licenses

Every file listed below is **CC0 1.0 (Creative Commons Zero / Public Domain
Dedication)** — free for any use, commercial or not, with no attribution required.
Attribution is given here voluntarily as good practice. No CC-BY or Pixabay-License
files were committed (see "Looked for but skipped" at the bottom).

All clips were sourced from **OpenGameArt.org**, downloaded from the page's own direct
download link, and the license string was read off the asset page before downloading.
Source files were transcoded/trimmed to small mono MP3s for the game; the originals are
not redistributed here.

## Looked for but NOT committed (license could not be verified / source gated)

- **Reverb impulse responses (room/hall).** The reputable free IR sets found (Voxengo,
  Immersive Soundscapes) are "free for any use" but **not** explicitly CC0 or CC-BY, and
  the CC0 IRs on Freesound require login to download. Per the strict license rule these
  were skipped — use the procedural reverb fallback.
- **Pixabay stingers/jumpscares.** Pixabay has good royalty-free (Pixabay Content
  License) jumpscares, but the site returns HTTP 403 to automated download and is
  JS-gated, so no file could be fetched and license-verified non-interactively. Skipped
  in favour of the verified CC0 qubodup metal impact above.
- **Little Robot Sound Factory "Horror Sound Effects Library"** (has knife-stab
  stingers) is **CC-BY 3.0**, not CC0, and only ships as a 70 MB zip — not worth the
  size/attribution overhead when a CC0 stinger was available. Skipped.
